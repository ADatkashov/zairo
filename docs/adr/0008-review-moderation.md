# 0008 — Модерация отзывов: жалуется бизнес, решает платформа

Дата: 2026-10-16. Статус: принято по умолчанию (политика ниже выбрана без отдельного подтверждения владельца
продукта — её легко изменить, см. «Что можно поменять»).

## Решение

- **Кто жалуется:** только бизнес, которому оставили отзыв (владелец, как и при ответе на отзыв). Клиент жаловаться не
  может — его отзыв и так подтверждён визитом.
- **Одна жалоба на отзыв навсегда.** Повторная (даже после отказа платформы) — 409. Это защита от «закопать» честный
  отзыв серией жалоб.
- **Решает платформа** (`PLATFORM_ADMIN` / `PLATFORM_MODERATOR`; `PLATFORM_SUPPORT` только читает): *скрыть* отзыв,
  *оставить* (закрыть жалобу) или *вернуть* скрытый. Каждое решение пишется в аудит-лог платформы, причина необязательна.
- **Скрытый отзыв не считается нигде:** ни в среднем бизнеса, ни в публичном списке и сводке, ни в рейтинге
  «Лучшие мастера», ни на странице мастера, ни в рейтинге мастера у владельца. Возврат восстанавливает всё.
- Владелец видит состояние жалобы на своей карточке отзыва («на рассмотрении», «скрыт», «оставлен»). Клиент свой отзыв
  по-прежнему видит у себя.

## Почему так

- Рейтинг — главный сигнал доверия; скрытие должно быть редким, видимым для платформы и обратимым.
- Автоматического скрытия по жалобе нет: бизнес не должен иметь рычага влиять на свой рейтинг без человека.

## Что можно поменять

- Разрешить жалобы клиентам/мастерам — новый эндпоинт рядом с `POST /reviews/{id}/report`.
- Автоскрытие или лимит жалоб — в `ReviewService.reportReview`.
- Уведомлять бизнес о решении — событие после `ReviewModerationService.*`.
