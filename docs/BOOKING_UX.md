# Запись: выбор услуги, даты и времени (UX-решения)

Принцип проекта: удобство человека прежде всего (`CLAUDE.md`). Ниже — что мы увидели в потоке записи (экран
бизнеса → подтверждение), что изменили и от чего сознательно отказались. Решения принимались по снятым экранам
(390 и 360 px, тёмная тема, русский).

## Что было не так
1. **Порядок «мастер → услуга → время» и время в самом низу.** Чтобы увидеть слоты, нужно было прокрутить
   ~1,5 экрана и сделать три выбора. Мастер по умолчанию не выбирался, поэтому пока не тапнешь «Любой мастер»
   или мастера, времени нет вообще («Who would you like to see?»).
2. **Тяжёлая нижняя панель** (степпер + подсказка + сумма + кнопка, ~170 px): список слотов виден в узком окне;
   выбранные день и время в панели не показывались.
3. **Плоская «стена» чипов** со временем без группировки; не было пути «просто ближайшее» и календаря месяца,
   чтобы планировать вперёд.
4. После выбора услуги/мастера время оставалось за экраном — его приходилось искать.

## Что стало
| Решение | Зачем |
|---|---|
| **Услуга → специалист → время** (услуга первой) | Услуга определяет, кто и когда свободен; в «любой мастер» без услуги слотов нет. |
| **«Любой мастер» по умолчанию**, в одну строку «Специалист: Любой мастер ▾» | Один шаг меньше; список мастеров не отодвигает время (раньше ~600 px). Выбор конкретного человека — один тап, после него список сворачивается, строка называет мастера. |
| **«Ближайшее»**: три самых ранних времени одним тапом («Сегодня 16:00», «Завтра 10:00») | Большинству нужно «первое свободное»: запись за 2 тапа (услуга → время), если услуга одна — за 1. |
| **Полоса дней + календарь месяца** (дни со свободным временем активны, остальные приглушены и читаются как «нет времени») | Быстрый выбор рядом и обзор месяца для планирования вперёд. |
| **Время по частям дня** (утро / день / вечер), если в дне больше шести времён | Длинный список легче сканировать; в коротком заголовки — шум, их нет. |
| **Автопрокрутка к времени** после выбора услуги или специалиста (когда слоты загрузились) | Следующий шаг всегда на виду. |
| **Компактная нижняя панель**: подсказка («Выберите время»), услуга, **выбранные день и время**, сумма, «Записаться» | Выбор подтверждается на глаз до тапа; на ~50 px больше места под слоты. Степпер с этого экрана убран (он остаётся на экранах оплаты и подтверждения). |
| Карточка записи в «Моих записях»: суммы на всю ширину, статус в нижней строке | Раньше блок оплаты сжимался в узкую колонку и переносил слова. |

## Компромиссы и что не делали
- «Любой мастер» по умолчанию: тот, кто хочет конкретного человека, делает один дополнительный тап по строке
  «Специалист». Выбрали экономию шага для большинства.
- Занятые слоты не показываем (зачёркнутые чипы только шумят): видно только то, что можно выбрать.
- Время показывается в часовом поясе устройства. Для клиента в другом городе это может ввести в заблуждение;
  показ часового пояса бизнеса — отдельная задача.
- Полноэкранные шаги «мастер/контакты/оплата» из референсов не делали: контактные данные уже в профиле,
  оплата отдельным экраном появляется только при предоплате, а один длинный экран с автопрокруткой быстрее
  пошагового мастера.
