# Идея: онлайн-консультации внутри ZAIRO

Статус: **идея, отложена** (решение от 2026-10-25). Код не пишется.
Референс: приложение «эксперт + чат + видеозвонок» (список экспертов, профиль,
чат, видео, выбор времени, оплата, история встреч).

## Суть

Не отдельное приложение, а ещё одна вертикаль внутри ZAIRO (рядом с beauty,
auto, cleaning): клиент находит эксперта, записывается на онлайн-консультацию,
оплачивает, общается в чате и/или созванивается.

## Что уже есть в ZAIRO

| Экран референса | Готовая база |
|---|---|
| Список экспертов, поиск, фильтры | `providers`, `catalog`, `search`, `favorites` |
| Профиль эксперта, отзывы | профиль провайдера, `reviews` |
| Чат | `messaging` (conversation на пару клиент+провайдер) |
| Выбор времени | `booking`, `staff`, расписание, `waitlist` |
| Оплата | `payments`, `payment-provider`, `saved_card`, возвраты |
| История встреч | история броней (другой фильтр/экран) |

## Что нового

1. **Видеозвонок** — единственная по-настоящему новая часть. Только через
   готовый сервис (LiveKit / Agora / Daily / Zoom SDK): токены комнаты, таймер,
   разрешения камеры/микрофона, экран звонка.
2. **Вертикаль `vertical-expert`**: специализация, стаж, формат, цена за час.
3. **Онлайн-бронь**: вместо адреса — ссылка/комната, напоминание за 15 минут,
   кнопка «Войти» активна только в окно встречи.
4. **Realtime в чате** (WebSocket/SSE), при необходимости — файлы.

## Решение: когда

**Сейчас не делаем.** Причины:
- ZAIRO — маркетплейс местных услуг; онлайн-эксперты — другой рынок и другая
  конкуренция.
- Сначала нужно набрать провайдеров и брони в текущих категориях.
- Видео дорогое (внешний сервис, оплата минут, проверка на устройствах,
  правила возврата при сорванном звонке), а спрос не проверен.
- Для врачей/юристов возможны юридические требования.

## Этапы, когда вернёмся к идее

1. **Проверка спроса (1–2 недели, без видео).** Тип брони «онлайн-консультация»:
   оплата + чат + ссылка на звонок во внешнем сервисе (Zoom/Meet/Telegram).
   Можно начать с существующих провайдеров (например, стилист или автоэксперт
   отвечает платно в чате).
2. **MVP вертикали.** Отдельный тип «эксперт» (или провайдеры из
   `business_admin`), профиль, фильтры по специализации, история встреч.
3. **Встроенное видео** — только если этап 1 показал спрос.

## Открытые вопросы

- Какой видеосервис доступен и стабилен на нашем рынке?
- Эксперты — обычные провайдеры из `business_admin` или отдельный тип с
  модерацией?
- Какие категории (психолог, юрист, маркетолог, врач) и какие для них
  юридические ограничения?
- Правила возврата: эксперт не пришёл, связь оборвалась, клиент опоздал
  (сверить с `PAYMENT_STATE_MACHINE.md`).

## Удобство пользователя (по принципу из `CLAUDE.md`)

- Не вводить новую нижнюю навигацию: раздел «Онлайн» — плитка/вкладка на
  главной.
- Путь «Записаться → время → оплата» не длиннее 2–3 тапов, как в
  `BOOKING_UX.md`; экраны времени и оплаты переиспользовать, не рисовать заново.
- Продумать пустое состояние, ошибку звонка, плохую сеть, 320 px, тёмную тему
  и три языка.

## Тестирование

Бэкенд и Flutter — по правилам `CLAUDE.md` (автотесты в том же коммите, порог
покрытия не снижать). Видео в тестах мокается, поэтому живую проверку на
телефонах нужно делать вручную.
