# Промт для Claude Design — редизайн всей платформы (3 приложения)

Вставить целиком в Claude Design (с подключённым репозиторием `adatkashov/zairo`, ветка `develop`).

---

## Роль

Ты — senior product designer уровня Apple / Airbnb / Linear / Stripe / Vercel. Тебе доступен код репозитория и текущий дизайн. Задача — **довести дизайн всей платформы до уровня самых трендовых, популярных и красивых приложений 2026 года**, не ломая существующую функциональность. Три приложения должны ощущаться как **одна семья** (общий язык, токены, компоненты), но каждое — под свою аудиторию и сценарий.

## Три приложения

Все — Flutter (Material 3, go_router, Riverpod), общая дизайн-система в `packages/core_ui` (tokens: `factory_colors`, `factory_typography`, `factory_spacing`, `factory_radius`, `factory_elevation`, `factory_motion`; виджеты `Factory*`). Описание системы: `docs/design-review/FACTORY_DESIGN_SYSTEM.md`, замечания: `docs/design-review/AUDIT_FINDINGS.md`. Языки RU / KK / EN (тексты бывают длинными), светлая и тёмная темы обязательны.

### 1. `apps/user_app` — клиентское приложение (consumer)
Аудитория: обычные люди, mobile-first (iOS/Android). Эмоциональный, «вкусный» consumer-дизайн уровня Airbnb / Booksy / Fresha / Uber / Apple Wallet.
Разделы: discovery (поиск, категории), каталог, карты, карточки салонов/мастерских/мастеров, booking (выбор услуги, времени, подтверждение), мои записи, платежи, избранное, лояльность, сообщения, уведомления, отзывы, профиль, настройки, выбор города, auth. Вертикали: beauty, auto, cleaning.
Фокус: визуальная привлекательность, фото-first карточки, плавные переходы, быстрый путь к записи в 2–3 тапа, доверие (рейтинги, отзывы, цены).

### 2. `apps/business_admin` — Business Platform (владельцы и модераторы бизнеса)
Аудитория: владельцы салонов/мастерских, часто с телефона между клиентами; также планшет и web.
Разделы: dashboard, salon, beauty, auto, cleaning, catalog, staff, messaging, reviews, loyalty, campaigns, automation, billing, moderation, city, settings, storage, auth.
Фокус: ясный дашборд (Bento), календарь/записи, быстрые действия, понятные метрики, плотность там, где это работа.

### 3. `apps/platform_admin` — консоль сотрудников платформы
Аудитория: внутренние сотрудники; web — основной сценарий, плюс Android/iOS/desktop.
Разделы: dashboard (обзор), businesses (модерация), catalog, cities, finance (выплаты, возвраты), activity (журнал), staff, settings, auth. Навигация: bottom bar < 768px, rail 768–1199, sidebar ≥ 1200 (`FactoryBreakpoints`).
Фокус: data-heavy интерфейс уровня Stripe Dashboard / Linear — таблицы, фильтры, статусы, бейджи «требует внимания», command palette, плотные, но читаемые списки.

## Что сделать

1. **Изучи код и текущий вид** всех трёх приложений и `core_ui`.
2. **Ревизия**: что выглядит устаревшим, перегруженным, непоследовательным; слабая иерархия; пустые / ошибочные / загрузочные состояния; расхождения между приложениями.
3. **Единая визуальная система** для всех трёх + **осознанные различия** между ними (consumer — теплее и эмоциональнее; business — рабочий и ясный; platform — плотный и аналитический).
4. **Применяй актуальные тренды без перегиба**:
   - чистый минимализм, сильная типографская иерархия, воздух; высокая плотность только в таблицах/календаре;
   - Bento-сетки для дашбордов: одна «героическая» метрика, остальные вторичны;
   - мягкие многослойные поверхности, тонкие 1px-границы + деликатные тени, glass/blur только для навигации и оверлеев;
   - современные градиенты и «ambient glow» в акцентных местах, не залитые экраны;
   - крупные tabular-цифры, sparklines, прогресс-кольца, тренд-бейджи (▲ +12%);
   - скругления 16–24 карточки, 12 контролы; сетка 4/8pt;
   - крупные фото, hero-карточки, карусели, sticky-CTA, bottom sheets (user_app);
   - микроанимации и переходы (staggered reveal, shared-element, skeleton → контент, press states), с учётом `reduce motion`;
   - command palette / быстрый поиск, swipe-действия, быстрое добавление;
   - продуманные empty/error состояния с иллюстрацией и CTA;
   - dark mode — отдельно настроенный, не инверсия;
   - доступность: контраст ≥ 4.5:1, цель касания ≥ 44px, фокус-состояния, масштабирование шрифта.
5. **Бренд-основа**: сейчас stone `#F7F6F3`, Pine `#1B5C52` (dark `#4FCFB4`), Gold `#C99A3E`, шрифты Unbounded + Golos Text + JetBrains Mono. Можешь пересобрать палитру, типографику и компоненты, если это даёт заметно лучший результат; каждое изменение токенов обосновывай. «Factory» — кодовое имя, не финальный бренд.

## Ограничения

- Реализация — Flutter/Material 3 поверх `packages/core_ui`; не предлагай то, что нельзя разумно собрать виджетами.
- Не менять бизнес-логику, маршруты, API.
- Тексты локализованы (`l10n/app_{ru,kk,en}.arb`) — не хардкодь строки, учитывай длину RU/KK.
- Дизайн должен работать для всех вертикалей (beauty, auto, cleaning) и расширяться на новые.
- Производительность: без тяжёлых blur/шейдеров в длинных списках.
- Изменения общих токенов и компонентов делаются в `core_ui` один раз для всех приложений; специфика приложения — в его `app/theme`.

3. Токены и компоненты `core_ui` (точные значения, таблицы, состояния default / pressed / focused / disabled / loading / error).

5. План внедрения по шагам для Claude Code: 1) токены и базовые компоненты `core_ui`; 2) user_app; 3) business_admin; 4) platform_admin.
