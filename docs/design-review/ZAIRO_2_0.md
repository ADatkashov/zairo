# ZAIRO 2.0 — «Pine & Brass»: состояние редизайна

Дата: 2026-10-09. Документ фиксирует **что реально сделано**, что не сделано и
почему, чтобы следующий заход не начинал с нуля и не принимал заготовку за
готовый результат.

Figma-файл: <https://www.figma.com/design/XlSDA1Zhwcs1NvDpERv6L3> (на тарифе
Starter, редактируемый).

## Направление

Палитра Pine + Brass, три шрифта (Unbounded, Golos Text, JetBrains Mono) и
шкала 4pt остаются: они проверены на контраст AA и поддерживают русский и
казахский. Поэтому 2.0 — это **язык компонентов и композиция экранов**, а не
новая палитра:

- тональные (мягко залитые) поля и вторичные кнопки;
- выбранное состояние — тон + рамка + галочка, а не сплошная заливка;
- состояние никогда не передаётся одним цветом (иконка/зачёркивание/текст);
- числа (цены, время, KPI) — моноширинный шрифт с табличными цифрами;
- три «темпа» поверх общих токенов: `FactoryAppProfile.consumer / business /
  platform` (радиус карточек 24/16/12, высота строки 64/56/40).

## Что сделано в Figma

Файл на тарифе Starter: **3 страницы**, поэтому 7 разделов оформлены секциями:

| Страница | Секции | Статус |
|---|---|---|
| Foundations | 1 · Cover & Vision | готово |
| | 2 · Design System (цвета Light/Dark, типографика, отступы, радиусы, тени) | готово |
| | 3 · Shared Components | **частично** |
| | 7 · Responsive & States | не начато |
| User App | 4 · User App (экраны) | не начато |
| Business App · Platform App | 5 · Business App, 6 · Platform App | не начато |

- Переменные: `ZAIRO/Color Light`, `ZAIRO/Color Dark` (по 25 ролей из
  `FactoryColors`), `ZAIRO/Space`, `ZAIRO/Radius`, `ZAIRO/Size`.
  Светлая и тёмная палитры — отдельные наборы: на Starter разрешён один режим
  на набор.
- 18 стилей текста и 3 стиля тени (значения из кода).
- Компоненты с variants: Button (5 видов × 2 размера × 4 состояния), Chip,
  Status badge, Time slot, Input, Service row, Payment breakdown (3 режима
  `PaymentPlan`), Stat tile, List row, Toggle, Checkbox, Radio.
- **Не созданы:** иконки, нижняя навигация, поле поиска, toast, диалог, bottom
  sheet, avatar, tab, строка таблицы, все экраны трёх приложений, состояния
  (loading / empty / error / success), прототипные связи.

### Почему на этом остановились

Figma MCP на тарифе Starter даёт **20 вызовов инструментов в месяц**
(`rate-limits-access.md` сервера Figma). Лимит исчерпан; запись в файл
невозможна до сброса или смены тарифа (Professional + Full/Dev seat: 200
вызовов в день). Страницы и режимы переменных ограничены тем же тарифом.

## Соответствие Figma → код

| Figma | Код (`packages/core_ui`) |
|---|---|
| Button / Secondary (тональная) | `FactoryButtonVariant.tonal` — **добавлено** |
| Button / Outline | `FactoryButtonVariant.secondary` (контурная, без изменений) |
| Button / Primary, Text, Danger | `primary`, `text`, `danger` (без изменений) |
| Chip / Selected=true | `FactoryChip(selected: true)` — тон + рамка + галочка, **изменено** |
| Input | `inputDecorationTheme` — тональная заливка, **изменено** (см. ниже) |
| Time slot | `FactoryTimeSlot` — 44×44 (PR #173) |
| Service row | `FactoryServiceCard(selected: …)` (уже совпадало) |
| Payment breakdown | `BookingPaymentSummary` / `PaymentPlan` (уже совпадало по сути) |
| Stat tile | `FactoryStatTile` + `FactoryTrendBadge` (без изменений) |

**Отступление от Figma — поле ввода.** В макете поле в покое без рамки. В коде
оставлена тонкая рамка `border` (1px): без неё граница тональной заливки на фоне
страницы почти не видна (нетекстовый контраст), а метка поля это не компенсирует.
Фокус — 2px `primary`, ошибка — 1.5px `error`, как в макете.

## Что сделано в коде

Только `packages/core_ui`, общее для всех трёх приложений:

- `FactoryButtonVariant.tonal`;
- выбранный `FactoryChip` — мягкий тон с галочкой;
- тональные поля ввода с кольцом фокуса и ошибки;
- тесты на все три изменения.

Экраны `user_app`, `business_admin`, `platform_admin` **не переделывались**:
макетов экранов в Figma нет, а переписывать работающие экраны (платежи,
бронирование, права доступа) «по описанию» без макета небезопасно.

## Реальные разделы приложений (по коду, не по ТЗ)

Платформа: Обзор, Бизнесы, Каталог, Города, Финансы, Журнал, Сотрудники,
Настройки. Отдельных разделов «Пользователи», «Подписки и тарифы», «Отчёты и
аналитика» **в приложении нет** — их нужно сначала согласовать с бэкендом, а не
рисовать как существующие. Подписка владельца бизнеса есть в `business_admin`
(Billing).
