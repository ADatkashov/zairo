# Инструкции для Codex по этому репозиторию

## Ветки и git-workflow (с 2026-11-04)

Единственная рабочая ветка — **`main`** (основная ветка репозитория). Коммитить и
пушить в неё можно сразу, без отдельного подтверждения. Старые ветки `develop`,
`test`, `master` больше не используются: в них не коммитить, не пушить и не мержить,
пока пользователь явно не скажет иначе.

Это правило будет пополняться другими заметками по мере необходимости.
